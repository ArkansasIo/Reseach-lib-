RESEARCH PLATFORM · v0.1.1

Neural Research Library

A TypeScript research platform for discovering, cataloging, indexing, and experimentally evaluating AI and neural-network research. MySQL provides the persistent research catalog while scheduled jobs automate source ingestion.

View Repository Roadmap

Research Discovery

Search and ingest AI papers from arXiv, with normalized titles, authors, abstracts, categories, identifiers, and source metadata.

MySQL Research Graph

Track papers, authors, tags, models, datasets, experiments, observations, and research-run history.

Scheduled Jobs

node-cron runs recurring research ingestion and provides a foundation for future cleanup, indexing, and analysis workers.

AI Experiments

Store hypotheses, model configurations, datasets, metrics, seeds, and runtime metadata for reproducible experiments.

Research lifecycle

discover → normalize → deduplicate → store → tag → analyze → experiment → observe

Local development

git clone https://github.com/ArkansasIo/Reseach-lib-.git
cd Reseach-lib-
cp .env.example .env
npm install
docker compose up -d mysql
npm run db:migrate
npm run research
Research output should be validated against primary sources and reproducible experiments. Respect source terms, licensing, API limits, and robots policies.
